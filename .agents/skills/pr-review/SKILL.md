# pr-review

1. Read changed files and relevant tests first; skip unrelated files.
2. Report concrete findings with severity and affected paths or lines.
3. Check regressions, edge cases, and security or privacy risks.
4. Identify missing validation or test coverage.
5. Present findings first, then assumptions or questions, and a concise summary.
