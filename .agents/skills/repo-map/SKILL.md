# repo-map

1. Inspect top-level folders and safe manifests such as `package.json`, Python metadata, requirements files, and task files.
2. Record install, test, lint, format, build/typecheck, and docs commands only when evidenced in the repository.
3. Use TODOs for unknown commands rather than inferring conventions.
4. Summarize the stack and documentation or runbook locations.
5. Propose only minimal, evidence-backed `AGENTS.md` updates.
