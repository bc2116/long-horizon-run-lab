# Long Horizon Run Lab — Public Portfolio Guidance

## Privacy boundary

- This repository is public and must contain only synthetic demo records.
- Never copy live training notes, health values, routes, identities, private
  Sites metadata, or Git history from the private edition.
- Keep the public API read-only unless a separate authenticated multi-user design
  is explicitly implemented and reviewed.

## Verified commands

- Develop: `npm run dev`
- Test: `npm run test`
- Lint: `npm run lint`
- Build: `npm run build`
- No formatter or standalone typecheck script is currently declared.

## Documentation and quality

- Product overview: `README.md`
- Data and methodology guide: `docs/RUNNING-TRACKING-DOCUMENTATION.md`
- Before a commit or deployment, run the relevant checks and report any skipped
  validation explicitly.
